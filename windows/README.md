# Chroma 2D – Beta 1 (Windows)

GitHub limits files to 100 MB, so the game comes in 4 parts. Download all of them
into the same folder:

1. [Chroma2D-beta-windows.zip.part0](https://github.com/joshuamrumack-collab/chroma1/raw/main/windows/Chroma2D-beta-windows.zip.part0)
2. [Chroma2D-beta-windows.zip.part1](https://github.com/joshuamrumack-collab/chroma1/raw/main/windows/Chroma2D-beta-windows.zip.part1)
3. [Chroma2D-beta-windows.zip.part2](https://github.com/joshuamrumack-collab/chroma1/raw/main/windows/Chroma2D-beta-windows.zip.part2)
4. [Chroma2D-beta-windows.zip.part3](https://github.com/joshuamrumack-collab/chroma1/raw/main/windows/Chroma2D-beta-windows.zip.part3)
5. [join.bat](https://github.com/joshuamrumack-collab/chroma1/raw/main/windows/join.bat)

Then:

- Double-click **join.bat**. It makes `Chroma2D-beta-windows.zip` from the parts.
- Unzip it and double-click **Chroma2D.exe**.
- If Windows says "Windows protected your PC", click **More info** → **Run anyway**.
  Test builds aren't signed, so Windows doesn't recognise them yet.

Every chapter and level is open from the start (Chapters on the title screen). The controls
are in the README inside the zip.

Found a bug or got stuck? Note the level (for example 3-4) and what you were doing.
