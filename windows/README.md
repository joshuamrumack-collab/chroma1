# Chroma 2D: Windows build

The build is split into parts because GitHub limits files to 100 MB.

1. Download all 4 `Chroma2D-windows.zip.part*` files into one folder.
2. Join them:
   - Double-click `join.bat` in the same folder, or
   - in Command Prompt: `copy /b Chroma2D-windows.zip.part0+Chroma2D-windows.zip.part1+Chroma2D-windows.zip.part2+Chroma2D-windows.zip.part3 Chroma2D-windows.zip`
3. Unzip `Chroma2D-windows.zip` and run `Chroma2D.exe`.

This is a testing build: every chapter and level is open from the start.
