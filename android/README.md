# Chroma 2D – Beta 3 (Android)

GitHub limits files to 100 MB, so the app comes in 3 parts. On a Windows PC:

1. Download [part0](https://github.com/joshuamrumack-collab/chroma1/raw/main/android/Chroma-beta.apk.part0), [part1](https://github.com/joshuamrumack-collab/chroma1/raw/main/android/Chroma-beta.apk.part1), [part2](https://github.com/joshuamrumack-collab/chroma1/raw/main/android/Chroma-beta.apk.part2) and [join.bat](https://github.com/joshuamrumack-collab/chroma1/raw/main/android/join.bat) into one folder.
2. Double-click **join.bat**. It makes `Chroma-beta.apk`.
3. Copy `Chroma-beta.apk` to your phone (USB, Google Drive, email...) and open it there.
4. If Android asks, allow installing apps from that source. If Play Protect warns you, choose "Install anyway": test builds aren't from the Play Store.

Needs Android 7 or newer on a 64-bit phone. Touch controls: move pad on the left; Jump (again in mid-air to brush hop), Absorb and a Paint/Color switch on the right; drag to paint; tap a paint well to pick it, Mix then a well to mix.
